## 자기소개

저는 전북대학교 컴퓨터인공지능학부 3학년 2학기에 재학 중인 김성운입니다. 사용자 화면부터 서버와 데이터 처리까지 서비스의 전체 흐름을 이해하는 풀스택 개발자를 목표로 공부하고 있습니다.

이 사이트에는 직접 진행한 학습과 프로젝트의 과정, 확인한 결과를 기록합니다.

## 관심 분야와 선택 이유

관심 분야는 다양한 환경에서 사용할 수 있는 서비스와 접근성을 고려한 소프트웨어 개발입니다. 기능이 동작하는 것뿐 아니라, 사용자의 기기와 운영체제가 달라도 서비스를 이용할 수 있도록 만드는 과정에 관심이 있습니다. 현재 참여 중인 캡스톤 프로젝트의 Android 지원 확대를 이러한 관점을 배우는 기회로 삼고자 합니다.

[GitHub에서 작업 보기](https://github.com/kimsungwoon5056-beep/MyProfile)

## 학습 목표와 실행 계획

### 기존 코드 분석과 플랫폼 호환성

이번 학기에는 기존 코드의 구조를 이해하고, 공통 기능과 플랫폼별 기능을 구분하는 역량을 기르는 것이 목표입니다.

1. 기존 프로젝트의 실행 흐름과 iOS 종속 요소를 정리합니다.
2. 팀에서 합의한 담당 범위에 따라 Android 실행 과정의 문제를 재현하고 검증합니다.
3. 매주 작업 내용과 오류, 확인 결과를 기록하여 다음 작업의 우선순위를 정합니다.

### 풀스택 서비스 구현

작은 웹 기능 하나를 화면, API, 데이터 저장까지 연결해 구현하고자 합니다. 정상 입력과 잘못된 입력을 각각 확인하고, 구현 과정과 실행 방법을 문서로 남기는 것을 목표로 합니다.

위 항목은 앞으로 수행할 학습 계획이며, 완료한 작업과 확인한 결과는 [학습 기록](../posts/)에 구분하여 추가하겠습니다.
